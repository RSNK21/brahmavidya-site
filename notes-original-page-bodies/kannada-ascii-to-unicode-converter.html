Install Brahmavidya Kannada Word Add-in

This stand alone Microsoft Word add-in converts selected Kannada text inside Word. Use one ribbon button for legacy NUDI ASCII to Unicode and another for Unicode to legacy ASCII. Conversion works completely offline, so document text stays on your computer.

Installation instructions

  1. Select Download MS Word Kannada Add-in.
  2. Open the ZIP and extract BV_Kan_ascii2uni.exe.
  3. Close every Microsoft Word window.
  4. Right-click the installer and select Run as administrator.
  5. Select Install, then reopen Word.
  6. Open the Brahmavidya Kannada ribbon tab.
  7. Select text, then choose the required conversion button.

Beta version: Windows may show an Unknown Publisher warning because the installer is not commercially code-signed. After installation, conversion needs no internet connection.

Windows document utility

Install BVDoClean — Document Cleaner

BVDoClean is a native Windows utility for Microsoft Word (.docx, .doc) and OpenDocument (.odt) files. It removes invisible bloat — revision identifiers, proofing markers, redundant language tags, duplicate embedded fonts, unreferenced hidden bookmarks, orphaned settings and stored metadata — while leaving visible text, layout, footnotes and headers untouched. The cleaned document keeps its original format.

Installation instructions

  1. Select Download Doc/ODT/Docx Cleaner and save BVDoClean.exe.
  2. The program is a single self-contained file — no setup wizard, no extra software. Keep it in any folder on your computer.
  3. If Windows SmartScreen shows an Unknown Publisher warning, choose More info → Run anyway. The program is not commercially code-signed.
  4. Double-click BVDoClean.exe, open a .docx or .odt file with the button or by drag-and-drop, then choose Clean Save.
  5. For batch work, use the command line: BVDoClean.exe --cli input.docx [output.docx].

Note: .doc files require Microsoft Word to be installed; they are cleaned through Word automatically. .docx and .odt files are cleaned natively with no extra software.

Using the Inna Swaralipi Font

Inna Swaralipi is a Kannada font for Carnatic music notation, built on Baraha’s BRH Kannada Music Keys 2 with eleven gamaka symbols added by Brahmavidya. Install the downloaded TTF on your computer (on Windows: double-click the file and choose Install), then select Inna Swaralipi in Word, Baraha, or any editor that lets you pick fonts.

Typing order

Type each note as swara, then an optional sthāyi dot, then an optional gamaka key — for example s1. The overlays attach to the preceding swara automatically and work in any renderer.

  • [ places the sthāyi dot above (mēla sthāyi); ] places it below (manda sthāyi).
  • 1 kampita · 2 sphurita · 3 pratyāghāta · 4 nokku · 5 ravai · 6 khaṇḍimpu · 7 vaḷi · 0 odukkal · – orikai.
  • 8 and 9 are inline jāru slide marks placed before or after a swara — for example s8p slides ಸ to ಪ.

Transliterate the generated Kannada Unicode into another scholarly script. The legacy ASCII output is never sent.

Runs only when you select Transliterate Unicode.

This optional action sends only the Kannada Unicode output to Aksharamukha’s public API. Core ASCII and Unicode conversion remains entirely in this browser.

Designed for difficult conjuncts

The conversion engine uses longest-match processing and Kannada cluster rules in both directions. Conjuncts, repha, ottakṣara, split vowel signs, and sequences such as ಗಣಪತಯೇ are handled as units rather than one character at a time.

Legacy fonts differ. Unicode to ASCII uses the canonical legacy form from this converter’s existing character table. If the status line identifies unmapped characters, compare the source font and the original document before publishing the result.
