    How the converter reads Kannada

    Nudi and Baraha store a letter as a heap of shapes: the body, the talakattu, the pieces of a vowel sign, each ottakshara, the arkavattu. The converter gathers each heap back into one akshara before it writes anything, so ಶ್ರೀ, ಸ್ತ್ರೀ, ಕಾರ್ಯ and ಉಜ್ಜ್ವಲ come out whole. It also accepts the different byte orders that older converters and typists produced, and it puts an akshara back together even when Word has split it across two runs of text.

    Going the other way, every legacy spelling was checked shape by shape in the NUDI 01 font, so the second ottakshara in ತತ್ತ್ವ sits beside the first, ಪು uses its own u-sign, and ಕೃ takes the right ṛ-sign with and without an ottu.

    Text between $ signs is left alone, which is handy for an English name inside Kannada. A visible halant, as in ಷಟ್‌ಶ್ರುತಿ, stays visible. Legacy fonts that use a different layout, such as Praja, need BV Mudrana.

    Install the Brahmavidya Kannada Word Add-in

    A Brahmavidya Kannada tab on Word's ribbon with two buttons: Nudi to Unicode, and Unicode to Nudi. Select some text, or select nothing to convert the whole document, headers, footers and footnotes included. Bold, italics, sizes, footnotes and pictures stay as they were. It uses the same engine as this page and works offline.

    Installation

    1. Select Download the add-in and open the ZIP.
    2. Close every Microsoft Word window.
    3. Double-click BV_Kannada_Word_AddIn.exe and choose Install. When Windows asks for permission to register the add-in, choose Yes.
    4. Open Word and go to the Brahmavidya Kannada tab.
    5. Pick the fonts you want for converted text from the two lists on the tab. Ctrl+Z undoes a conversion in one step.

    Already using version 1? Install 2.0 over it; it takes its place.

    Windows warning: the program is not commercially code-signed, so Windows may say it protected your PC. Choose More info, then Run anyway. To remove the add-in, run the same program and choose Remove.

    Windows document utility

    Install BVDoClean, the Document Cleaner

    BVDoClean is a native Windows utility for Microsoft Word (.docx, .doc) and OpenDocument (.odt) files. It removes invisible bloat (revision identifiers, proofing markers, redundant language tags, duplicate embedded fonts, unreferenced hidden bookmarks, orphaned settings and stored metadata) while leaving visible text, layout, footnotes and headers untouched. The cleaned document keeps its original format.

    Installation instructions

    1. Select Download Doc/ODT/Docx Cleaner and save BVDoClean.exe.
    2. The program is a single self-contained file: no setup wizard, no extra software. Keep it in any folder on your computer.
    3. If Windows SmartScreen shows an Unknown Publisher warning, choose More info → Run anyway. The program is not commercially code-signed.
    4. Double-click BVDoClean.exe, open a .docx or .odt file with the button or by drag-and-drop, then choose Clean Save.
    5. For batch work, use the command line: BVDoClean.exe --cli input.docx [output.docx].

    Note: .doc files require Microsoft Word to be installed; they are cleaned through Word automatically. .docx and .odt files are cleaned natively with no extra software.

    Kannada gamaka notation typeface

    Using the Inna Swaralipi Font

    Inna Swaralipi is a Kannada font for Carnatic music notation, built on Baraha’s BRH Kannada Music Keys 2 with eleven gamaka symbols added by Brahmavidya. Install the downloaded TTF on your computer (on Windows: double-click the file and choose Install), then select Inna Swaralipi in Word, Baraha, or any editor that lets you pick fonts.

    Typing order

    Type each note as swara, then an optional sthāyi dot, then an optional gamaka key, for example s1. The overlays attach to the preceding swara automatically and work in any renderer.

    • [ places the sthāyi dot above (mēla sthāyi); ] places it below (manda sthāyi).
    • 1 kampita · 2 sphurita · 3 pratyāghāta · 4 nokku · 5 ravai · 6 khaṇḍimpu · 7 vaḷi · 0 odukkal · – orikai.
    • 8 and 9 are inline jāru slide marks placed before or after a swara, for example s8p slides ಸ to ಪ.
